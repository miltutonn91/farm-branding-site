# 蓼科ごとう農園｜紹介サイト

## プロジェクトの概要

架空の農園「蓼科ごとう農園」の紹介サイトです。

デザインカンプをもとに、実務に近いコーディング力を高めることを目的に制作しました。

デザインの再現性を意識しながら、ファーストビュー、商品紹介、お知らせ、FAQなどのセクションを実装し、農園の雰囲気や商品の魅力が伝わるように制作しています。

## 開発環境構築方法

### 1. リポジトリをクローン

```bash
git clone https://github.com/miltutonn91/farm-branding-site.git
```

### 2. ディレクトリへ移動

```bash
cd farm-branding-site
```

### 3. ブラウザで確認

`index.html` をブラウザで開くことで、ローカル環境で表示確認できます。

本サイトは静的なHTML / CSS / JavaScriptで制作しているため、パッケージのインストールやビルド作業は不要です。
